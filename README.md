# 5071 地板滾球練習紀錄

採用 [5071 Open Design System](https://github.com/i3ustudio37/5071-open-design-system) 的 Next.js 網頁版單機 MVP。

## 使用功能

- 練習開始、暫停、繼續、結束；有效練習時間扣除暫停。
- 每球選擇紅／藍、貼球／一球距內／一球距外及八方位。
- 方位固定以投球者定義：長、長右、右、短右、短、短左、左、長左。依記錄者站位可切換投球者／對面記錄者視角（預設），畫面旋轉 180°，不改變儲存方位；箭頭標示投擲方向。
- 白球與色球等大，貼球的球緣間距為 0；一球距內／外示意分別為 ½／1½ 球徑，斜向保持同比例。
- 一次撿球自動收回場上所有球並完成一輪，保存對應逐球紀錄；無需選擇數量。
- 每輪分別顯示貼球命中率、含貼球的一球距內命中率、各類球數、八方位扇形圖與逐球明細。
- 主畫面扇形圖即時累積整場訓練，撿球不會重置；半徑依球數比例，紅色標示最多方位。
- 主畫面的退回上一球／復原撿球同步更新球數、輪次與圖表。
- 查看練習紀錄、逐筆時間、場上球數、貼球率、含貼球的一球距內比例與方位分布。
- 復原最近一筆投球／撿球；JSON 備份匯出與匯入。

## 行動版操作

手機為主要操作裝置，以 iPhone 12 的 390 × 844 CSS viewport 為主要版面。投擲、貼球及一球距內球數即時顯示（貼球與一球距內為獨立分類）；投球／撿球按鈕固定於底部，統計、歷史與備份收在右上角選單。平板與電腦使用響應式版面。

舊版備份仍可讀取；若舊版部分撿球沒有記錄球的對應關係，依同色投擲順序推算輪次，並在受影響輪次標示。結束時未撿回的球保留為「未撿球」，不當成已完成輪次。

## 紀錄保存

目前**只儲存在使用者的瀏覽器**，沒有登入或跨裝置同步。清除網站資料、更換瀏覽器、使用不同網址都會看到不同的本機資料；請在「練習紀錄」定期匯出備份。程式碼部署到 Vercel 不會將練習資料上傳到 GitHub 或 Vercel。

計時以時間戳還原：背景分頁或關閉頁面仍持續計時，休息時請按暫停。撿球期間也會持續計時。完成的場次不會繼續增加時間。

進行中的練習在匯出備份時會轉為暫停快照，保留匯出當下的時間，不影響本機持續計時。

備份匯入會合併未存在的場次，不覆寫相同 ID；同時只允許一場未結束練習。不同分頁更新衝突會提示重新整理，避免覆蓋新資料。

## 本機執行

需要 Node.js 22 以上。

```bash
npm ci
npm run dev
```

開啟 `http://localhost:3000`。

```bash
npm run typecheck
npm test
npm run build
npm start
```

無需環境變數、資料庫或付費服務。

## GitHub 與 Vercel

1. 將此資料夾推送到 `boccia-now` 儲存庫的 `main` 分支。
2. 在 Vercel 選取 **Add New → Project** 並匯入該 GitHub 儲存庫。
3. Framework Preset 使用 **Next.js**；Root Directory 使用儲存庫根目錄。
4. 保留預設的 `npm run build`，不需設定環境變數，按 Deploy。
5. 後續推送到 `main` 會自動部署；分支／PR 會產生預覽部署。

建議日常練習固定使用正式網址，避免不同預覽網址的本機資料互不相通。

## 結構與後續雲端同步

- `lib/practice.ts`：獨立於畫面的資料型別、時間計算、場上球數與輸入驗證。
- `lib/storage.ts`：非同步保存介面及版本化 JSON 格式，目前使用 localStorage。
- `app/page.tsx`：練習與歷史紀錄介面。
- `styles/5071/`：原始設計 token；`components/brand.tsx` 與 `public/5071/` 使用官方 Logo 與 Lucide。

未來可替換 storage 介面加入登入、使用者資料隔離與雲端資料庫，沿用既有 UUID 場次及事件；仍需實作離線佇列、衝突解決與本機資料搬移，第一版沒有假造同步狀態。

## 設計來源

5071 的 `DESIGN.md` 為視覺規範來源。官方 Logo 原圖保留，主題使用炭黑、緋紅單一主操作與語義 token。Saira / Saira Condensed / JetBrains Mono 用於 UI 與數字，中文字使用裝置可用字體。球色屬於運動紀錄的語義資訊。
