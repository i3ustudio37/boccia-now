# BC3 AIM LAB — 軌道瞄準 MVP

靜態網頁；不需要資料庫、API、帳號或建置工具。

## 操作與座標

投擲區固定寬 1.00 公尺、深 2.50 公尺。原點為投擲區前緣中點，x 右正左負、y 向球場正前方為正。

- 白球 J = (左右座標 xj, 前方距離 yj)；前方距離從投擲區前緣起算。
- 軌道旋轉中心 P = (左右座標 xp, -b)；xp ∈ [-0.5,+0.5] m，b ∈ [0,2.5] m。
- 目標方向 θ = atan2(xj - xp, yj + b) × 180/π。
- 相對目前方向需旋轉 Δθ = wrap180(θ − θ0)。
- 正前方為 0°；向右（順時針）為正，向左（逆時針）為負。
- 可以在 SVG 圖中拖曳藍點來改變旋轉中心。

本 MVP 僅計算二維幾何中心線通過白球中心，不包含坡度、出球動力學、軌道中心線偏置、器材干涉或競賽規則合法性檢查。

## Vercel

此程式位於獨立目錄 \`bc3-aim-mvp/\`，在 Vercel 選擇這個目錄作為 Root Directory；Framework Preset = Other；不需 Build Command。由 GitHub main branch 自動部署。

## 測試

用瀏覽器直接開啟 index.html，或於此目錄啟動 \`python3 -m http.server 8080\`。可對照下列幾何測試：
- J=(0,5)，P=(0,-1.25)：0°
- J=(1,5)，P=(0,-1.25)：atan2(1,6.25)≈+9.09°
- J=(-1,5)，P=(0,-1.25)：≈-9.09°
