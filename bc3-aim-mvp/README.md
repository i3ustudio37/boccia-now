# BC3 AIM LAB — 六投擲區全場軌道瞄準模擬器（v2）

網站：https://bc3-aim-lab.vercel.app

## 場地幾何與座標系

本模擬器採用 World Boccia 2025–2028 規則的完整 6.00 × 12.50 m 球場：

- 投擲區：6 個，由面向球場時左到右編號 1–6；每區 1.00 m 寬 × 2.50 m 深。
- 投擲線／區域前緣：全場原點 (0, 0)，在六區前緣中點。
- x 軸：右正左負，範圍 -3～+3 m。
- y 軸：比賽區往前為正，投擲線前方 0～10 m；投擲區後方 -2.5～0 m。
- V 字線：頂點 (0, 1.5 m)，兩端 (-3, 3 m)、(+3, 3 m)。
- 十字及 35 × 35 cm 罰球目標框：(0, 5 m)。
- 場地線寬及球體半徑未納入數值判定，因此 V 線提示不是正式裁判判決。

規則與場地圖：https://www.worldboccia.com/about-boccia/rules/

## 使用步驟

1. 選擇 1～6 號投擲區，或點選場地圖中的投擲區。
2. 輸入白球位置：由投擲線向前幾公尺、相對全場中線向左／右幾公尺。
3. 輸入軌道旋轉中心：相對該投擲區中心左右偏移、由投擲線向後幾公尺。
4. 若已知目前軌道角度，可輸入「目前角度」；未知時保持 0°。
5. 閱讀「相對正前方瞄準角」和「相對目前方向旋轉」，並比較六區結果。
6. 可拖曳黃色白球、藍色旋轉中心。每區的旋轉中心和目前角度設定在此次頁面開啟期間分別保留；重新整理則恢復預設。

## 計算

投擲區 n 的中心全場 x 座標：xc = n − 3.5。

該區旋轉中心相對中心偏移 dx（-0.5～+0.5m），向後距離 b（0～2.5m）：

P = (xc + dx, −b)

白球座標 J = (xj, yj)，其中 yj 是從投擲線往前的距離。

瞄準角 θ = atan2(xj − xc − dx, yj + b) × 180 / π。

若目前軌道角度 θ0，應旋轉角度 Δθ = wrap180(θ − θ0)。

正前方 0°、右轉順時針為正、左轉逆時針為負。

例：白球 (0, 6m)、每區中心偏移 0、向後 1.25m：

| 投擲區 | 旋轉中心全場 x (m) | 瞄準角 |
|---|---:|---:|
| 1 | -2.50 | +19.03° |
| 2 | -1.50 | +11.69° |
| 3 | -0.50 | +3.95° |
| 4 | +0.50 | -3.95° |
| 5 | +1.50 | -11.69° |
| 6 | +2.50 | -19.03° |

## MVP 限制

只計算幾何中心線指向白球中心。假設軌道中心線通過底座旋轉中心；未處理出球後運動、軌道坡度、球速、碰撞、地面摩擦、底座和輪椅的實際尺寸、旋轉限位及設備干涉。V 字線提醒僅依球心座標概略判定。未證明此系統可於正式競賽合法使用。
